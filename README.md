# Capstone 2

To view Capstone 2 click [here]()

Capstone 2 is a site where you can improve your health by setting macro nutrient goals for yourself and planning out meals to follow them! 

## How To Use
First thing you want to do when you go to the site is make an account! After that feel free to explore the rest of the site. There is a lot of potential things to do! \
Such as: 
 - View your macro goals for each day and see if you have hit those goals or not
 - Manually add a meal into the meal planner
 - Search for meals you might be interested in 
 - Add meals from the search onto your meals planner
